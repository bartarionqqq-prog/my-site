# Foodie☆ — сайт поиска недорогих заведений

Многостраничный учебный проект в эстетике японских персональных сайтов 2000-х: kawaii, pastel, pixel details, аниме-иллюстрация, декоративные GIF-слоты.

## Страницы

- `index.html` — главная с баннером, быстрым поиском и популярными заведениями.
- `search.html` — поиск, категории, фильтр по среднему чеку и сортировка.
- `place.html?id=1` — подробная карточка заведения и отзывы.
- `favorites.html` — избранные места.
- `profile.html` — демонстрационная страница профиля.

## Стек

- HTML5, CSS3, JavaScript (без сборщика).
- Node.js + Express — API.
- PostgreSQL — база данных.
- pgAdmin 4 — графическое управление PostgreSQL.
- Google Fonts: M PLUS Rounded 1c, Nunito, Press Start 2P.

## 1. Установить зависимости

Установи Node.js LTS и PostgreSQL. Затем открой терминал в папке проекта:

```bash
npm install
```

## 2. Создать базу в pgAdmin 4

1. Открой pgAdmin и подключись к своему PostgreSQL Server.
2. Открой Tools → Query Tool на базе `postgres`.
3. Открой и выполни `database/01_create_database.sql`. Он создаст базу `foodie_star`.
4. В дереве слева обнови Databases и выбери `foodie_star`.
5. Открой Query Tool уже на `foodie_star`.
6. Выполни по очереди `database/02_schema.sql` и `database/03_seed.sql`.
7. В разделе Schemas → public → Tables должны появиться таблицы `users`, `categories`, `places`, `favorites`, `reviews`.

**Важно:** pgAdmin — это программа управления PostgreSQL, а не сама база данных. Сервер PostgreSQL должен быть установлен и запущен.

## 3. Подключить сервер к PostgreSQL

1. Скопируй `.env.example` в файл `.env`.
2. В `.env` укажи свой пароль PostgreSQL в `DB_PASSWORD`.
3. Проверь `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`.
4. Не публикуй `.env` и не загружай пароль в Git.

Пример:

```env
PORT=3000
DB_HOST=localhost
DB_PORT=5432
DB_NAME=foodie_star
DB_USER=postgres
DB_PASSWORD=твой_пароль
```

## 4. Запустить сайт

```bash
npm start
```

Открой в браузере: `http://localhost:3000`.

Проверка соединения с БД: `http://localhost:3000/api/health`.

## GIF-анимации

В корне проекта могут находиться `maskot.gif` и `anime-bocchi.gif`.
Запусти `install-gifs.bat` в Windows — скрипт скопирует их в `public/assets/gif/`.
Можно скопировать вручную, сохранив точные имена:

- `public/assets/gif/maskot.gif` — маскот в шапке, на главном баннере и в профиле.
- `public/assets/gif/anime-bocchi.gif` — анимация в боковых блоках главной страницы и поиска.

GIF загружаются через `data-gif` в HTML. Если файла нет, остаётся аккуратная заглушка.

## Картинки заведений

У каждого заведения отдельная локальная иллюстрация в `public/assets/places/`. Путь к ней хранится в поле `places.image_url` и используется карточками, избранным и страницей заведения.

## Важные замечания перед реальным запуском

- В демонстрации используется `USER_ID = 1`, поэтому избранное общее для демо-пользователя.
- Настоящая регистрация, авторизация, хеширование паролей, роли и защита API ещё не включены.
- Для публичного production-размещения обязательно добавить авторизацию, валидацию, rate limiting, HTTPS, секреты окружения и политику обработки персональных данных.
- Цены и адреса в seed — демонстрационные данные, не реальные предложения заведений.


## Персональные иллюстрации заведений

У каждого заведения теперь отдельный файл в `public/assets/places/`:

- `anime-cafe.png` — Кафе «Аниме»
- `moon-cafe.png` — Кофейня «Moon»
- `kawaii-sushi.png` — Суши-бар «Kawaii»
- `cloud-cafe.png` — Кофейня «Cloud»
- `pixel-burger.png` — Бургерная «Pixel»
- `berry-patisserie.png` — Кондитерская «Berry»

Путь к файлу хранится в `places.image_url`. Карточки, поиск, избранное и страница заведения берут изображение из этого поля. Для новой базы используй обновлённый `database/03_seed.sql`. Если база уже была создана ранее, выполни один раз `database/04_update_place_images.sql` в pgAdmin.

## Поиск и фильтрация

- Категории фильтруются по `categories.slug`: `cafe`, `pizza`, `sushi`, `fastfood`, `coffee`, `dessert`.
- Поиск работает по названию, описанию, адресу и категории.
- Добавлены синонимы: например, «кофе», «кофейня», «латте» находят кофейни; «бургеры» — фастфуд; «роллы» — суши и роллы.
- Результаты обновляются при вводе, а фильтры цены и сортировки применяются сразу.
- Если PostgreSQL временно недоступен, те же фильтры работают по демонстрационным данным в `public/js/app.js`.
